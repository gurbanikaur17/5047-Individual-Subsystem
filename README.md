# COMP5047-Individual-Subsystem
 
Subsystem chosen - Warden
TASK 2 - ONE main functional requirement chosen - 1) Authentication, Roster & Shift Handover
Quality requirements of this functional requiement:
1) Security - There should be proper authorisation and authentication in place, following a zero-trust model where only authorised personnel can access the database containing sensitive information like staff details and rosters for upcoming weeks, pay info etc.
2) Performance - The system should be fast and efficient, updating data and locations of the wardens, mentioning what part of the accommodation they are in, and where they are currently patrolling. The authentication process should also be smooth yet robust.
3) Reliability - The chances of system failure should be minimised, by creating a low latency system with redundancy in place so that if one part of it fails, the other parts aren't affected. 
4) Scalability - The system must have sufficient memory to handle the extensive user database, both of the students living in the accommodation and the staff working there. As the number of students grows especially during Induction week (at the start of a new academic year), it must be able to keep all user's data strictly confidential and ensure a smoothly working UI at the same time.
